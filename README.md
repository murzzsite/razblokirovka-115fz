# Разблокировка счетов по 115-ФЗ — лендинг
Чистый HTML/CSS/JS. Заявки: Cloudflare Worker lead-relay, ref 6NBQAEVEPU (клиент должен нажать «Старт» в боте).
Шрифты Geologica (заголовки) + Golos Text. Светлая тема, поле меняется красный→зелёный по скроллу (идея: счёт «размораживается» вместе с прокруткой).
Живая вещь: калькулятор «Сколько стоит простой» (считает по данным посетителя, ничего не выдумано).
Заменить/уточнить: реквизиты оператора в privacy.html, скидка за объём (условия), измеримый результат (цифры конверсии), отзывы/кейсы (нет — не выдумывали), ссылка на MAX (есть только номер).
Цвета с сайта isn-consult-group.ru (синий #4C8BF5→#2A62D6 для кнопок, navy #1E3A8A, ink #1E293B); 4 согласия обязательны перед формой и перед переходом в Telegram (окно #gate). Тексты 3 из 4 документов — заглушки до переноса на домен. Оператор: ИП Ииева С.Н., ИНН 526021058560 (с её сайта).
