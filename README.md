# Разблокировка счетов по 115-ФЗ — лендинг
Чистый HTML/CSS/JS. Заявки: Cloudflare Worker lead-relay, ref 6NBQAEVEPU (клиент должен нажать «Старт» в боте).
Шрифты Geologica (заголовки) + Golos Text. Светлая тема, поле меняется красный→зелёный по скроллу (идея: счёт «размораживается» вместе с прокруткой).
Живая вещь: калькулятор «Сколько стоит простой» (считает по данным посетителя, ничего не выдумано).
